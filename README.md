# Lumi — универсальный Discord-бот + веб-панель

Lumi — программный комплекс: Discord-бот (музыка, экономика, модерация, ИИ-чат,
лицензии) + веб-панель (OAuth2-вход, оплата Stripe, личный кабинет, управление сервером).

- Язык: Python 3.12 (бот, API), HTML/CSS/JS (сайт)
- Объём: ~8 000 строк исходного кода (Python ~6 400, веб ~1 700)
- Версия: 2.4.x

## Состав

| Файл | Назначение | Строк |
|---|---|---:|
| `bot.py` | Точка входа бота: события, 60+ команд, ИИ-агент (20 раундов), лицензии, лимиты, фоновые задачи | ~2 100 |
| `discord_tools.py` | 66 инструментов агента: серверы, тикеты, экономика, embed | ~1 700 |
| `database.py` | SQLite-слой: 20+ таблиц, лицензии CREATED/ACTIVE/EXPIRED/REVOKED, ИИ-лимиты | ~1 450 |
| `components.py` | Кнопки, модалки, панели (опросы, тикеты, верификация) | ~1 150 |
| `web_server.py` | FastAPI: OAuth2, Stripe + webhook, API, rate-limit, healthcheck | ~480 |
| `music.py` | Музыкальный движок: очередь, плеер, приоритеты | ~300 |
| `services.py` | Внешние сервисы: погода, валюты, перевод, викторины | ~190 |
| `mailer.py` | Email-уведомления о покупке (SMTP) | ~40 |
| `site/` | Лендинг, премиум, кабинет, панель, юр. страницы | ~1 700 |
| `render.yaml` / `Dockerfile` / `lumi-bot.service` | Деплой: Render, Docker, systemd | — |

## Запуск

```bash
pip install -r requirements.txt
python -X utf8 -u bot.py         # бот (нужен .env с DISCORD_TOKEN)
python -X utf8 web_server.py     # панель (нужен .env с OAuth/Stripe)
```

Шаблон настроек — [.env.example](.env.example). Файл `.env` с секретами
не распространяется и не коммитится.

## Лицензирование продукта

Продажи идут лицензионными ключами `LU-XXXX-XXXX` (FunPay / Stripe):
ключ одноразовый, при активации привязывается к Discord ID покупателя
(личный — на любом сервере, серверный — на одном), есть отзыв `!revoke`,
аудит `!чек`, состояния CREATED/ACTIVE/EXPIRED/REVOKED.
