# Lumi — универсальный Discord-бот

Lumi — многофункциональный Discord-бот на Python (discord.py):
AI-чат с автоматическим fallback на бесплатные модели, генерация изображений,
автоматическая сборка клановых серверов (RUST), экономика, уровни, голосования,
тикеты, авто-мод, напоминания, ивенты, дни рождения и многое другое.

## Состав

| Файл | Назначение |
|---|---|
| `bot.py` | Точка входа: события Discord, команды, AI-агент, фоновые задачи |
| `discord_tools.py` | Инструменты AI-агента (66 шт.): клан-сервера, картинки, экономика, сервисы |
| `components.py` | Кнопки, модальные окна, панели (голосования, тикеты, верификация и др.) |
| `database.py` | SQLite-слой: 19 таблиц (экономика, варны, напоминания, ивенты, БД и т.д.) |
| `services.py` | Внешние сервисы: погода, курсы валют, перевод, викторины, мемы |
| `lumi.db` | База данных (создаётся автоматически, не распространяется) |

## Запуск

```bash
python bot.py   # настройки — в .env (не распространяется)
```

## Лицензирование конечных сборок

Распространяемые сборки (например, Lumi.exe) используют систему лицензионных
ключей Ed25519, привязанных к HWID: без действительного ключа программа
не запускается. Настройки лицензий — `lumi_master_keys.json`.
