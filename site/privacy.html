Политика приватности

Последнее обновление: 2026-08-26

1. Какие данные собираем

  • Discord ID, username, avatar — при входе через OAuth2.
  • ID серверов, где вы админ и бот присутствует — для панели управления.
  • Лицензионные ключи, историю покупок, промокоды — для премиума.
  • IP-адрес, User-Agent — в логах безопасности (до 30 дней).

2. Для чего используем

  • Авторизация и идентификация в личном кабинете.
  • Выдача и проверка премиум-ключей.
  • Показ ваших серверов в панели управления.
  • Безопасность: защита от брутфорса, DDoS, фрода.

3. Передача третьим лицам

Не передаём данные третьим лицам, кроме:

  • Stripe — платёжные данные (мы не видим номер карты).
  • Discord API — для работы бота и OAuth.
  • По требованию закона / суда.

4. Хранение и удаление

  • Аккаунт и ключи — пока вы не удалите аккаунт (напишите в поддержку).
  • Логи безопасности — 30 дней, затем автоудаление.
  • Платёжные данные — у Stripe по их политике.

4. Ваши права (GDPR / 152-ФЗ)

  • Доступ к данным — напишите в поддержку, вышлем JSON.
  • Удаление аккаунта — полная стирания за 30 дней.
  • Ограничение обработки — отказ от аналитики.

5. Cookies

Только lumi_token (HttpOnly, Secure, SameSite=Lax) — сессия авторизации. Трекинг-куки не используем.

6. Безопасность

HTTPS везде, токены в HttpOnly куках, rate limiting, валидация вебхуков Stripe, параметризованные SQL-запросы.

7. Контакты

DPO / вопросы по данным: Discord-сервер поддержки.
