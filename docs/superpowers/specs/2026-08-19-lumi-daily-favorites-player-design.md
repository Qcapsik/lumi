# Дизайн: Дневной бонус + Избранное + Живой плеер

Дата: 2026-08-19 · Статус: принят пользователем · Реализация: bot.py, music.py, database.py, discord_tools.py

## 1. Живой плеер
- Карточка трека (embed): обложка, название, исполнитель, **прогресс-бар** `▬▬◔▭▭` + время.
- `music_loop` обновляет карточку раз в 5 сек через `player.control_message.edit`.
- Кнопки под карточкой: ⏭️ скип (синяя), ⏹️ стоп (красная), 🔁 повтор (зелёная), 🔉/🔊 громкость, 👋 выход.

## 2. Избранное (до 20 треков на юзера)
- Таблица `favorite_tracks` (user_id, title, url, duration, thumb, webpage_url, added_at; UNIQUE(user_id,url)).
- `!люб <название>` — поиск (SoundCloud) и добавить; «already», «limit» — понятные ответы.
- `!любимое` — список по номерам; `!любимое 3` — играть №3; `!любимое 0` — весь плейлист; `!любимое -3` — удалить.
- `!плейлист` — просмотр списка.
- Ачивка `fav_first` «Коллекционер».

## 3. Дневной бонус
- Таблица `daily_streak` (user_id PK, last_date, streak, best).
- `!день` — раз в сутки: награда `50 + 10×(streak−1)`, кап 150 кредитов; пропуск дня → streak сбрасывается на 1; рекорд сохраняется.
- Серия 7+ дней → ачивка `daily_7` «Неделя наград».

## Требования
- Никаких внешних ключей/ключей; всё в SQLite; все команды работают в free-режиме без API-ключей.
- Прогресс-бар рисуется по времени запуска трека (позиции в стриме нет).
