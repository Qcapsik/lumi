# Дизайн: Музыка в голосовых каналах + Прогресс (ачивки, профиль-карточка) + Фокус-сессии

Дата: 2026-08-19
Проект: Lumi (Discord-бот). Решение по итогам брейншторма (подход A).

## 1. Цель

Сделать Луми ещё более многофункциональной:
1. Реальное проигрывание музыки из YouTube в голосовых каналах.
2. Система достижений (ачивок) с уведомлениями и списком прогресса.
3. Профиль-карточка, рендеримая в изображение (Pillow).
4. Фокус-сессии с таймером и личными отчётами.

Ограничения: всё должно работать через уже существующие механизмы (discord.py 2.7.1,
aiohttp, Pillow 12.3.0). Бот не должен падать ни при каких ошибках слоя музыки/картинок.

## 2. Архитектура

Новый модуль `music.py` — единственное место, где живёт состояние голосовых каналов:
- `MusicPlayer`: очередь track'ов, текущий трек, повтор очереди, громкость,
  события завершения трека (on_after).
- `get_player(channel)` — реестр плееров по guild_id.
- Поиск и скачивание аудио: `yt_dlp.YoutubeDL` с `formataudio/best*, extractaudio=True`.
- Тех. зависимости: `discord.py` voice требует `PyNaCl`; `yt-dlp`; ffmpeg — статик-билд,
  путь к ffmpeg передаётся как параметр в run_process (ffmpeg.exe рядом с проектом в `ffmpeg/`).

Существующие файлы:
- `bot.py`: команды и фон. Добавляются: обработчики музыкальных команд, `!ачивки`,
  `focus_loop` (каждые 20 сек), обработчик `!фокус`, регистрация ачивок в on_message/on_voice.
- `discord_tools.py`: `render_profile_card(user, stats)` — Pillow-рендер, `list_achievements`,
  `unlock_achievement` (обёртка над БД + уведомление).
- `database.py`: таблицы `achievements`, `focus_sessions`.
- `components.py`: без изменений (кроме import music при необходимости — не требуется).

## 3. Музыка

Команды (русские + прямые синонимы из tools_map для AI):
- `!плей <название|ссылка>` / `!play` — поиск первого результата yt-dlp; бот заходит
  в голосовой канал автора; трек ставится в очередь; embed с названием и длительностью.
- `!скип` / `!sk` — пропустить текущий трек.
- `!стоп` — очистить очередь и выйти из канала.
- `!очередь` — список до 15 треков (embed).
- `!громкость 1-100` — громкость плеера (VolumeTransformer).
- `!повтор` — toggle повтора очереди.
- `!выход` / `!leave` — выйти, если бесхозный >5 минут — выход автоматический.

Поведение:
- Очередь до 50 треков.
- Конвертация = стримовая: `-re -i url -c copy -f mp3 pipe:1`? Не в 1-й версии:
  используем chained audio source (discord.py `FFmpegPCMAudio` с stdin из yt-dlp).
- Ошибки: yt-dlp недоступен/ошибка извлечения → embed «Не удалось найти трек», очередь не блокируется.
- Длительность > 3 часов — отклоняем.
- play_from_search: ytsearch1.

Требования окружения (установка):
- `pip install PyNaCl yt-dlp`
- ffmpeg: скачать статик-билд (gyan.dev essentials zip) в `D:\AI_CORE\ffmpeg\bin\ffmpeg.exe`.
  Путь задаётся константой `FFMPEG_PATH` в music.py с автоопределением (PATH/локальн.).

## 4. Ачивки (достижения)

Таблица `achievements(user_id INTEGER, ach_id TEXT, ts INTEGER)`:
- Каталог ~15 штук, каждый: id, эмодзи, название, описание, условие:
  | id | условие |
  |---|---|
  | first_message | первое сообщение |
  | msg_100 | 100 сообщений |
  | msg_1000 | 1000 сообщений |
  | voice_1h | 1 час в голосовом |
  | voice_10h | 10 часов |
  | lvl_5 / lvl_10 / lvl_25 | уровень 5/10/25 |
  | first_shop | первая покупка в магазине |
  | first_transfer | первый перевод кредитов |
  | first_quiz | первая викторина (отвечено) |
  | first_meme | первый мем |
  | warner | получил варн |
  | bday_set | указал день рождения |
  | member_year | участник больше года |
- Выдача: проверяется событийно (on_message после рег. XP, on_voice, покупка, перевод и т.д.)
  и периодической проверкой (флаги в БД). Проще: выдача в момент события.
- Уведомление: embed «🏆 Ачивка разблокирована: <эмодзи> <название>» в том же канале (для маркера).
- `!ачивки [@пользователь]` — embed: полученные + прогресс (N из 15).

## 5. Профиль-карточка (Pillow)

`!профиль` рендерит PNG 600x300:
- Фон: тёмный градиент + паттерн.
- Аватар пользователя (скачать через aiohttp; если не вышло — дефолтный круг с инициалами).
- Слева: уровень (большой), XP-бар с числом.
- Справа: ник, кредиты, «следующая ачивка» + 3 последние ачивки иконками.
- Текст: шрифт DejaVu Sans из Pillow (bundled; либо скачать Roboto в каталог проекта,
  при отсутствии — default font с fallback).
- Всё внутри try/except → при ошибке рендера возвращается текст-эмбед (fallback).

## 6. Фокус-сессии

- `!фокус N` (5–120) — запуск таймера N минут для автора.
- Пока сессия активна повторный `!фокус` запрещён (сообщение «сессия уже идёт»).
- По окончании: личное сообщение (DM) с embed-отчётом: длительность, кол-во сессий за
  7 дней, суммарные минуты, шуточная оценка.
- Таблица `focus_sessions(user_id, started_ts, minutes)`.
- `focus_loop` в bot.py (каждые 20 сек) ищет завершившиеся, шлёт отчёты, ремув из активных.

## 7. Обработка ошибок

- Музыка: всё в try/except; сообщение об ошибке в embed; никогда не ронять бота.
- Рендер карточки: try/except → текстовый фолбэк.
- yt-dlp: таймауты 15 сек; недоступность сети — очередь не ломается.

## 8. Тестирование и верификация

- `python -m py_compile` всех файлов.
- Import-смоук: `import music, database, discord_tools, bot` (с load_dotenv).
- Рендер карточки без сети: заглушка аватара → PNG создаётся.
- Музыка: `yt-dlp` поиск тестового трека (вручную при перезапуске/в канале).
- Перезапуск бота, проверка stderr без исключений.
